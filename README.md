A one-line, one-star review written by a houseplant about its human owner — an entry for the [One Star, Written in Sap](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) competition on make.fun.

## The review

> One star: he waters me every time his ex texts, so I'm rotting from the roots up and he has closure.

## How it works

`main.py` writes that exact line — and nothing else — to `entry.txt` in the output directory (`OUTPUT_DIR`, default `/output`). The output is fully deterministic: the same fixed text, byte-identical, on every run, with no trailing newline.
